# Capstone Project Idea: Zakat & Savings Tracker

## Project Overview
Zakat & Savings Tracker is a mobile application developed using Flutter and Dart. It aims to help users manage their personal assets, monitor savings goals, estimate their zakat obligations, and record zakat payments.

## Problem Statement
Managing personal savings, tracking assets, and calculating zakat can be difficult when financial information is scattered across notebooks or different applications. Users may struggle to maintain organized records, monitor savings progress, and track previous zakat payments.

## Proposed Solution
The application will provide a simple interface for registered users to manage their assets, set savings goals, estimate zakat based on eligible recorded assets and applicable rules, and record zakat payments. It will use a REST API backend and a relational database.

## Main Features
- User registration and login
- Create, view, update, and delete asset records
- Savings goal management
- Zakat estimation
- Zakat payment records

## Proposed Technologies
- Flutter and Dart
- REST API backend
- Relational database
- JSON
- Git and GitHub
